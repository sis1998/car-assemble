# 차량 조립 시스템 PRD

## 개요
사용자가 차량 타입과 부품을 선택하여 차량을 조립하고, 조립된 차량의 유효성을 검사하는 시스템

## 제조 순서

### 1단계: 자동차 타입 선택
다음 세 가지 타입 중 하나를 선택한다. 향후 타입이 추가될 수 있다.

| 타입 | 설명 |
|------|------|
| Sedan | 세단 |
| SUV | 에스유브이 |
| Truck | 트럭 |

### 2단계: 부품 선택
엔진, 제동장치, 조향장치를 각각 선택한다.

#### Engine
| 제조사 |
|--------|
| GM |
| TOYOTA |
| WIA |

#### BrakeSystem (제동장치)
| 제조사 |
|--------|
| MANDO |
| Continental |
| Bosch |

#### SteeringSystem (조향장치)
| 제조사 |
|--------|
| Bosch |
| Mobis |

### 3단계: 완성 차량 테스트
선택한 부품 조합이 해당 차량 타입에 사용 가능한지 검사한다.
