# 차량 조립 제약 조건

## 제약조건 1: 부품 간 호환성

- 제동장치에 **Bosch**를 사용한 경우, 조향장치도 반드시 **Bosch**를 사용해야 한다.
  - Bosch 제동장치는 타사 조향장치와 호환되지 않는다.

## 제약조건 2: 차량 타입별 사용 불가 부품

| 차량 타입 | 부품 종류 | 사용 불가 제조사 |
|-----------|-----------|-----------------|
| Sedan | BrakeSystem | Continental |
| SUV | Engine | TOYOTA |
| Truck | Engine | WIA |
| Truck | BrakeSystem | MANDO |
